# 徽州 · 富春山居：8 月中旬备骑重设计

日期：2026-07-27  
状态：已批准并实施  
前置：`2026-07-02-bikepacking-roadbook-design.md`（路线骨架仍有效）

## 1. 目标

在路线骨架不变的前提下，把产品叙事从「国庆硬挤」改成「8 月中旬全职备骑 → 9 月上中旬开骑」，并重做搭子页的信息架构与视觉系统，让合适的人留下、不合适的人自己退出。

## 2. 时间叙事

- **T0 ≈ 8 月 15 日**：失业 / 全职备骑开闸（主锚点）。
- **首选开骑窗**：9 月上旬–中旬（约 3–4 周备骑）。
- **国庆**：仅备选窗，方便仍需请假的搭子；不再作为唯一出发前提。

## 3. 路线边界（不变）

- 上海铁路接驳 → 安吉 / 皖南 → 徽州外围 → 新安江 → 富春江 → 杭州铁路返沪。
- Day 0–11 骨架、28C、不露营、免费公路风景优先、不从上海市区开骑：全部保留。

## 4. 产物分工

| 产物 | 任务 |
|---|---|
| `ride-with-me.html` | 筛选搭子 + 展示备骑诚意（含时间线、山→水视觉） |
| `roadbook.md` | 执行稿；含完整备骑时间线；日程骨架不动 |
| `route-options.md` | 仅更新旺季/假期风险措辞，方案结论不变 |

## 5. 搭子页信息架构

顺序：Hero → 备骑时间线 → 硬约束快照 → 路线弧线（地图收于此）→ 日程摘要 → 适合/不适合 → 约定 → 联系。

## 6. 视觉系统

- 避开暖纸白路书默认脸。
- 色：雾青底 `#E6EEF0`、墨青 `#0F1C1A`、竹海 `#1F4A3A`、江面 `#3A6B7C`、琥珀 `#C4783B`、雾面白 `#F3F7F8`。
- 字：LXGW WenKai（标题）+ Noto Sans SC（正文）。
- 签名元素：「山→水」里程丝带。

## 7. 验证

- Day 0–11 数据与 Roadbook 一致。
- 页内有「8 月中旬」备骑主锚点；国庆非唯一前提。
- 无 npm / 构建依赖；移动端首屏可读。
