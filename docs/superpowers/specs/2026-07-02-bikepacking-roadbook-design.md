# Bikepacking Roadbook 设计说明

日期：2026-07-02  
项目：徽州 · 富春山居 Bikepacking Roadbook  
状态：待用户确认

## 1. 目标

为一次从上海出发、国庆 / 中秋假期内完成的 bikepacking 旅行，生成一份可真正用于出行的 11 天 Roadbook，并配套一个用于寻找搭子的 HTML 网页。

这趟旅行的目标不是拉练，也不是刷数据，而是一条有风景、有节奏、有边界的长途骑行路线。路线应避免从上海市区直接开骑，因为市区红绿灯多、风景少，时间消耗不值得。默认策略是从上海高铁或动车到达风景更好的起点，开始正式骑行；终点选择可以高铁返沪的城市。

## 2. 骑行者约束

- 出发集散地：上海。
- 起点策略：上海高铁 / 动车接驳到风景起点后开骑。
- 返程策略：终点高铁 / 动车返沪。
- 骑行天数：约 11 天，整体控制在 12 天以内。
- 每日距离：100 km 上下，后期可以适当缩短。
- 强度节奏：前期可以略硬且风景要好；后期随着体力下滑，强度逐渐温和。
- 车辆：公路车。
- 外胎：28C。
- 路况要求：以柏油路为主，避免碎石路、林道、长距离破损县道，以及只适合 gravel 的路段。
- 爬升偏好：大多数日子尽量控制在 1500 m 以内；最多允许 1 天接近 1800 m，但必须有足够风景价值。
- 住宿方式：不露营。
- 住宿偏好：优先村镇民宿、特色客栈、景区外围民宿；城市酒店只作为兜底。
- 景点策略：不设置收费商业景区作为核心目标。整体以免费、开放、路过型的自然风景和公路风景为主，避开宏村 / 西递这类商业化较重且国庆人流密集的景点。
- 搭子风格：适合能稳定骑百公里、接受临时调整、重视风景和节奏胜过速度的骑友。

## 3. 推荐路线方向

以当前项目已有的“徽州 + 新安江 + 富春江”主题为核心，但对路线强度和路况做更适合 28C 公路车的调整。

推荐主线：

上海 -> 高铁到安吉 / 湖州 -> 安吉 -> 宁国 -> 青龙湾 / 储家滩 -> 皖南村镇 -> 绩溪 -> 歙县 / 徽州外围 -> 新安江 / 建德 -> 梅城 -> 桐庐 -> 富阳 -> 杭州 -> 高铁返沪。

这条线的核心气质是：

> 前半程从竹海和皖南山水进入徽州，后半程顺着新安江和富春江逐渐变温和。

它应该保留“徽州山水到富春江”的叙事感，但不应为了打卡所有网红山路或收费景区而牺牲路况、安全和恢复。对 28C 公路车来说，风景、铺装、车流和体力恢复必须一起平衡。

## 4. 需要保留的三条候选路线

最终项目中应包含一个路线对比文件，记录为什么选择主路线，以及其他路线为什么暂不作为默认方案。

### 方案一：徽州 + 新安江 + 富春江

这是当前项目最适合继续发展的路线。

优点：

- 与现有文档契合度最高。
- 旅行叙事完整。
- 前期有皖南山水和徽州文化。
- 后期自然转入新安江、富春江，强度逐渐变软。

缺点：

- 国庆期间皖南部分路段车流不可忽视。
- 个别县道路况需要谨慎筛选。
- 不适合硬贪所有网红山路。

### 方案二：安吉 / 莫干山外围 + 千岛湖 + 富春江

这是更公路车友好的浙西山水线。

优点：

- 路况更可控。
- 对 28C 更友好。
- 后半程恢复感强。
- 适合作为皖南路线风险过高时的备选。

缺点：

- 徽州文化厚度不如方案一。
- 千岛湖周边国庆车流和住宿价格可能较高。
- 故事性略弱于“徽州到富春江”。

### 方案三：婺源 / 徽州 + 新安江 + 富春江

这是风景兑现最快的一条路线。

优点：

- 高铁到达后很快进入风景密集区。
- 古村、山水、江河的旅行感强。
- 适合想把风景重心放在婺源 / 徽州外围山水公路的人。

缺点：

- 前期爬升更难压住。
- 国庆热门景区人流压力更大。
- 对 28C 公路车和住宿节奏的容错更低。

结论：默认采用方案一，并吸收方案二后半程更温和的收尾方式。

## 5. 11 天路线骨架

### Day 0：上海 -> 安吉 / 湖州

- 高铁 / 动车接驳。
- 装车、检查车况、补给采购。
- 可以轻松转一小段，也可以完全不骑。
- 住宿尽量避开最拥挤的城市核心区。

### Day 1：安吉 -> 广德 / 宁国方向

- 预计距离：90-105 km。
- 预计爬升：900-1300 m。
- 路线气质：竹海、丘陵、小镇、热身进入皖南。
- 目标：让身体进入长途节奏，不要第一天就爆。

### Day 2：宁国 -> 青龙湾 / 储家滩 -> 板桥 / 苏红外围

- 预计距离：80-95 km。
- 预计爬升：1200-1500 m。
- 路线气质：湖景、山路、皖南风景开始兑现。
- 重点：不要硬吃所有皖南川藏线热门段，尤其要避开国庆自驾车流最重的时间。

### Day 3：板桥 / 苏红 -> 绩溪外围 / 家朋取舍段

- 预计距离：75-95 km。
- 预计爬升：1300-1500 m。
- 路线气质：前半程最关键的山地日。
- 策略：准备两个版本，一条风景更好，一条路况和爬升更稳。当天根据天气、车流和体感选择。

### Day 4：绩溪 -> 歙县 / 徽州区

- 预计距离：75-95 km。
- 预计爬升：700-1200 m。
- 路线气质：从山地骑行转入徽州文化段。
- 住宿：优先古城外围或村镇民宿，不强求住城市酒店。

### Day 5：歙县 -> 徽州外围村镇 / 山水公路 -> 黟县 / 休宁

- 预计距离：70-90 km。
- 预计爬升：900-1300 m。
- 路线气质：徽州村镇和山水公路日。
- 景点策略：不进入宏村 / 西递等收费商业化景区。把时间留给开放道路、村镇边缘、田野、山谷和免费观景段。

### Day 6：黟县 / 休宁 -> 淳安或新安江方向

- 预计距离：90-110 km。
- 预计爬升：800-1300 m。
- 路线气质：从徽州山地逐步转向江河水系。
- 目标：开始从“山”切换到“水”，体感逐渐变柔。

### Day 7：新安江 / 淳安 -> 建德 / 梅城

- 预计距离：75-95 km。
- 预计爬升：500-900 m。
- 路线气质：江景、恢复、古镇。
- 住宿：优先梅城或建德江边民宿。

### Day 8：梅城 -> 桐庐

- 预计距离：75-95 km。
- 预计爬升：400-800 m。
- 路线气质：富春江核心舒适日。
- 目标：风景好，但不再硬拼强度。

### Day 9：桐庐 -> 富阳

- 预计距离：65-85 km。
- 预计爬升：300-700 m。
- 路线气质：江边骑行、恢复、咖啡、洗衣、慢节奏。

### Day 10：富阳 -> 杭州

- 预计距离：50-75 km。
- 强度：低。
- 路线气质：仪式感收尾。
- 可以当天返沪，也可以杭州住一晚。

### Day 11：机动日

- 用于天气、爆胎、疲劳、车流、住宿调整。
- 如果前面顺利，可以变成杭州轻松日、桐庐 / 富阳多停一晚，或提前返沪。

## 6. Roadbook 产物设计

生成 `roadbook.md`，作为真正出发时使用的完整指南。

建议章节：

- 封面与路线定位。
- 假期组合和时间策略。
- 上海出发与返沪交通策略。
- 路线总览。
- 适合谁 / 不适合谁。
- 28C 公路车约束。
- 装备清单。
- 修车与保养清单。
- 住宿策略。
- 饮食与补给策略。
- 每日路线。
- 每日风险。
- 摄影和停留建议。
- 免费风景优先策略。
- 撤退和调整方案。
- 搭子规则。
- 出发前最终检查清单。

每天的内容应包含：

- 起点和终点。
- 预计距离。
- 预计爬升。
- 难度。
- 路线气质。
- 路况预期。
- 风景亮点。
- 推荐住宿区域。
- 饮食和补给。
- 风险提醒。
- 保守版本。
- 风景版本，但必须适合公路车，且优先选择免费开放道路。

## 7. 找搭子 HTML 产物设计

生成 `ride-with-me.html`，作为用于邀请骑友的移动端优先网页。

这个页面不是完整 Roadbook，而是一张漂亮、清晰、有筛选能力的招募页。它应该让合适的人产生兴趣，也让不合适的人自动退出。

信息结构：

### 1. 首屏

- 旅行名称。
- 时间和天数。
- 路线气质。
- 一句话邀请。

### 2. 关键数据

- 11 天骑行。
- 约 900-1050 km。
- 每天约 100 km。
- 不露营。
- 公路车友好。
- 按 28C 外胎约束规划。

### 3. 路线弧线

- 上海高铁出发。
- 安吉 / 皖南山地。
- 徽州外围村镇和山水公路。
- 新安江。
- 富春江。
- 杭州 / 高铁返沪。

### 4. 适合加入的人

- 能稳定完成百公里日。
- 重视风景和节奏。
- 接受早起。
- 接受临时改线。
- 更喜欢路上的风景，而不是收费景区打卡。
- 会基础修车。
- 不追求豪华住宿。

### 5. 不适合加入的人

- 想要纯拉练配速。
- 无法接受国庆不确定性。
- 每天必须住城市酒店。
- 期待夜生活型旅行。
- 不能在混合车流中安全骑行。
- 强烈依赖热门景区打卡。

### 6. 每日路线卡片

- 用 11 张紧凑卡片展示每天路线。
- 展示距离、爬升、住宿类型、当天情绪标签。

### 7. 实际约定

- 费用 AA。
- 风险自担。
- 原则上不夜骑。
- 不露营。
- 安全和路线调整优先于打卡。
- 免费公路风景优先于收费景区。

### 8. 联系方式

- 留一个清晰的联系区域，由用户后续填写微信、电话或其他方式。

## 8. 视觉设计方向

找搭子网页应从当前 `roadbook.html` 的深色 emoji 卡片风格，升级为更克制、更耐读、更像旅行路书的视觉系统。

设计原则：

- 移动端优先。
- 手机上阅读舒适。
- 信息密度高，但不压迫。
- 有纸质地图 / Roadbook 气质。
- 更像旅行指南，不像竞技活动页面。
- 清楚筛选合适搭子。
- 卡片圆角控制在 8px 左右。
- 不用 emoji 做结构性图标。
- 用明确文字标签承载含义。
- 正文字号不低于 16px。
- 重点数据块和每日卡片尺寸稳定，避免布局跳动。

建议色彩：

- 背景：温暖的纸白色。
- 文字：深墨色 / 炭黑色。
- 山地强调色：低饱和绿色。
- 江河强调色：低饱和蓝色。
- 风险强调色：克制的朱红。
- 辅助底色：少量浅石色 / 地图米色，但不让页面变成单一米色主题。

需要避免：

- 大面积黑色 / 深蓝卡片。
- 紫色渐变。
- 装饰性光球、雾化背景、无意义渐变。
- 营销空话。
- 过大的首屏导致实用信息被压到很下面。
- 用 emoji 当导航或功能图标。

## 9. 数据与维护策略

本轮保持项目简单：

- 不引入构建系统。
- 不引入 npm 依赖。
- 使用手写 Markdown 和独立 HTML。
- `route-options.md`、`roadbook.md`、`ride-with-me.html` 分别维护。

未来如果内容继续扩大，可以再把每日路线数据抽成结构化文件，用数据生成 HTML，避免 Roadbook 和网页重复维护。

## 10. 验证计划

完成正式产物前应检查：

- 新文件是否都生成。
- Markdown 标题层级和表格是否正常。
- 如实施范围包含旧文件，应修复 `002-行前准备.md` 中未闭合代码块的问题。
- HTML 是否可以独立打开。
- HTML 在移动端和桌面宽度下是否可读。
- 是否误引入了不必要的依赖或构建要求。

## 11. 已知限制

- 第一版不生成精确 GPX，除非用户明确要求。
- 每日距离和爬升是规划估算，出发前仍需用地图工具复核。
- 临近出发前需要再次检查高铁班次、道路施工、景区规则和住宿可订情况。
- 当前环境无法启动视觉伴随服务，因为缺少 Node.js。
- 当前目录不是 Git 仓库，因此设计文档无法提交 commit，除非后续初始化仓库。
